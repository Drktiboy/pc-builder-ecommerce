# 🖥️ PC Builder E-Commerce (B2C)

## 📌 Descripción del Proyecto
Plataforma B2C de venta de componentes de hardware con un **Motor de Validación de Compatibilidad** en tiempo real. El sistema previene que los usuarios compren componentes incompatibles (ej. procesadores Intel en placas AMD o fuentes de poder insuficientes).

## 🛡️ Arquitectura y Seguridad
* **Frontend:** Angular.
* **Backend:** API REST segura.
* **Base de Datos:** MySQL.
* **Seguridad (OWASP):** Autenticación JWT, cifrado de contraseñas, prevención de inyección SQL y manejo estricto de transacciones ACID.
